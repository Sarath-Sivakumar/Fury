<h1>Fury:  Personal Finance Automation Platform</h1>


**🚀 Project Overview
**


Fury is a secure, automated personal finance assistant designed to help users bridge the gap between spending and saving. By combining a robust Spring Boot backend with a real-time Flutter mobile interface, the platform provides actionable insights into spending habits and uses predictive algorithms to help users reach their financial goals.


**🛠 Technical Architecture
**


Backend: Java 17+, Spring Boot, Spring Data JPA.




Security: JWT (JSON Web Tokens) for stateless authentication and encrypted storage for sensitive financial data.




Mobile: Flutter (Dart) for a high-performance, cross-platform user experience.




Database: PostgreSQL for reliable transaction logging and Redis for caching frequent financial queries.


Quality Assurance: SonarQube for vulnerability scanning and JUnit for testing core business logic.


**✨ Key Features
**


Automated Spending Analysis: Custom Java services that categorize transactions and identify spending patterns.


Savings Prediction: Implementation of algorithms that forecast future savings based on historical data trends.


Seamless Data Sync: Real-time synchronization between the mobile frontend and backend services via optimized REST APIs.




Secure API Design: Validated REST endpoints ensuring data integrity and protection against common OWASP vulnerabilities.




**📊 Impact & Results
**


Improved Discipline: Successfully helped users improve financial discipline through automated insights.


High Engagement: Designed to support a growing user base of over 1,000 active users.


Optimized Performance: Leveraged efficient data patterns to ensure real-time financial updates with minimal latency.
